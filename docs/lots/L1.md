Choix d'implémentation faits pendant la réalisation (imitation de `docs/architecture.md`) :

- register et login ont chacun leur limiteur (10 requêtes / 15 min par IP et par route), pas un compteur commun.
- Les routes sont déclarées avec leur chemin complet : le motif journalisé est `req.route.path`, sans `baseUrl`.
- Unicité du nom de personnage sans casse : index unique `lower(name)` écrit en SQL ; Prisma ne signale aucun écart.
- `requireAuth` précède `validate` : sans jeton, une route protégée répond 401 avant toute validation.
